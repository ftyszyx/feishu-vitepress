每个采集的微博账号都会在本地生成一个独立的归档目录。归档数据会自动去重，并在后续采集中持续累加。

本文介绍微博归档的目录结构，以及修改、删除和导入归档的方法。

## 1.1 支持的操作

1. 修改归档目录位置
2. 归档目录发生变化后，导入已有归档并继续预览
3. 删除不再需要的归档

# 1. 查看归档目录位置

在设置中，可以查看软件当前使用的所有归档目录位置。

# 4. 导入已有归档

如果归档目录被移动了，可以通过导入功能重新关联。

点击“导入本地归档”。

<img src="/assets/SeVTbk1ZboxnmJx295ucFJDMnKe.png" src-width="413" class="markdown-img m-auto" src-height="424" align="center"/>

选择需要导入的归档目录。

 

<img src="/assets/MqgUbcC55ooP6GxmzT6c8PBlnwe.png" src-width="1753" class="markdown-img m-auto" src-height="1059" align="center"/>

导入成功后，即可在软件中预览归档内容。
