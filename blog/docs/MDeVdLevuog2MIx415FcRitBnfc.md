Wemory是一款超级厉害的工具：

1. 读取和备份微信聊天记录
2. 读取和备份微信朋友圈记录
3. 导出好友列表
4. 导出群成员列表
5. 公众号批量采集和导出
6. ai工具支持

以上功能全支持，而且界面美观易用。

现在介绍一下主要功能：

### 1.1.1 聊天记录：按会话浏览，按范围导出

Wemory 支持浏览私聊、群聊和企业会话，可按联系人或群组查看内容，也可以搜索、筛选并批量选择会话。聊天记录支持导出为 HTML 或 PDF，便于离线阅读、归档和分享。

常见的文本、图片、视频、语音、表情、附件和折叠消息都可以在统一的聊天视图中整理。对已经在微信中加载到本机的图片或语音，刷新本地资源后即可继续查看；未下载的视频也会显示封面，方便快速确认内容。

### 1.1.2 朋友圈：按时间重新浏览自己的记录

朋友圈内容可以按时间浏览，并按需导出为 HTML 或 PDF。对于希望保存个人生活记录、整理项目过程或回顾重要阶段的用户，这是一种更适合长期阅读和备份的方式。

<img src="/assets/PwUtbx34Eo9O57xrWz4cKTNKnqI.png" src-width="2920" class="markdown-img m-auto" src-height="1717" align="center"/>

### 1.1.3 通讯录：联系人与群成员一并整理

Wemory 可以查看微信联系人和群成员，并将联系人、群成员及相关标签导出为 XLSX。需要做客户整理、团队盘点或个人资料备份时，可以直接在表格中继续处理。

<img src="/assets/Pu90bhtNEoGjqRxjMRQc1GLvnge.png" src-width="1892" class="markdown-img m-auto" src-height="927" align="center"/>

### 1.1.4 公众号：批量采集与导出

公众号文章可以批量采集、集中浏览和导出，适合整理长期关注的行业资料、学习内容和个人收藏，减少重要文章散落在聊天列表中的查找成本。
